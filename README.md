# Price Comparison UI

## About the Project
Developed a responsive **Price Comparison Web Application** (`PricecomparisionUI`) that helps users search, filter, and compare product prices across different platforms in one place to find the best deals.

🔗 **Live Demo:** [https://pricecomparision-6e9c3.web.app](https://pricecomparision-6e9c3.web.app)

## Technologies Used
- React.js
- JavaScript (ES6+)
- HTML5 & CSS3
- Bootstrap / Tailwind CSS *(update with the styling library you used)*
- Firebase Hosting

## Features
- **Product Search & Filtering:** Quickly search for items and filter results by category, brand, or price range.
- **Side-by-Side Price Comparison:** Compare product prices, ratings, and availability across multiple sellers.
- **Best Deal Highlights:** Automatically highlights the lowest price or best value option for users.
- **Responsive UI:** Optimized for smooth browsing across desktop, tablet, and mobile screens.

## Key Functionalities
- Component-based architecture built with React.
- Dynamic state management for real-time search, sorting, and filtering.
- Responsive UI layout and interactive product comparison cards.


## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder and install dependencies:
   ```bash
   cd your-repo-name
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
